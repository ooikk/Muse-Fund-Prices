Compare Funds

Plot fund performance over a period, rebased to 100 at the start date so funds with very different prices can be compared on one chart. History comes from FundSingapore.

Funds to compare

Only funds listed on FundSingapore can be plotted — the history comes from its fund library, using the fund ID from the fund's page link (id=…). A fund FundSingapore has stopped updating (e.g. Janus) has no history and shows as "No data".

Period

Each fund's line starts at 100 on the first day of the period. Returns are growth in each fund's own currency — there is no currency conversion. Click a column header in the table to sort by it.

FundReturnFromToData points

Your comparison fund list is stored in this browser (localStorage) on this device. When the page is opened with a shared-list link (?u=…), the list is shared through Upstash Redis under that code — the same code as the main tracker list — so it loads on any device; if no shared list exists for the code yet, this browser's list is uploaded once. History is fetched live from FundSingapore (/api/timeseries proxy) each time you change period or refresh; nothing is stored on the server. FundSingapore's API is undocumented and could change — if it stops working the page says so instead of drawing a wrong chart.
